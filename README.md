# mrsliva-s-home

Личный сайт с проектами [mistersliva](https://github.com/mistersliva) в стиле Windows 10 / UWP (Modern UI, Fluent).

- **Главная**: живые плитки, как в меню «Пуск» (часы, профиль, проекты)
- **Проекты**: список с вкладками-Pivot по языкам и поиском
- **Страница проекта**: факты о проекте и README прямо с GitHub
- **Параметры**: тёмная/светлая тема и цвет акцента, как в Windows 10

Список репозиториев загружается из GitHub API при открытии страницы. Если API недоступен, показывается встроенный список из `app.js`.
Скрытые репозитории перечислены в `HIDDEN` в начале `app.js`.

Сборка не нужна: это обычные статические `index.html`, `style.css` и `app.js`.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.
